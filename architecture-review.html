Revisión de Arquitectura y Diseño de Módulos

Diagnóstico estructural para resolver la sincronización temporal y el solapamiento visual.

YOLO MODE ACTIVE

⭐ Recomendación Principal: Sincronización Temporal de Servidor Unificada (Módulo Profundo)

El problema de que los contadores queden "atrás" o "interpuestos" se debe a un modelo de diseño de estado **superficial**. El cliente intenta adivinar de forma independiente cuándo se regenerará la energía del usuario, creando una duplicidad de lógica de negocio (en StatsContext.js y UserStatus.js).

Nuestra propuesta consiste en crear un Time Sync Module en el cliente que calcule el desfase exacto del servidor (Server Offset) durante el login/carga y exponga un único reloj atómico unificado para todos los contadores de la aplicación.

Fricción de Estado Recomendación: Fuerte

Desincronización de Energía

Archivos involucrados: lib/auth.js, context/StatsContext.js, components/sidebar/UserStatus.js.

Problema: El servidor regenera energía "al vuelo" dividiendo el tiempo transcurrido por 5 minutos. El cliente intenta calcularlo en paralelo, pero cualquier latencia de red o desfase horario hace que la barra de energía salte bruscamente al realizar llamadas a la API.

Solución: El backend devolverá el nextRegenerationTime (timestamp del próximo tick) en lugar de dejar que el cliente lo deduzca. El cliente creará un módulo de sincronización profunda que se suscribirá a este tick para actualizar la energía local exactamente cuando lo haga el servidor.

Fricción Visual (Layout) Recomendación: Explorar

Solapamiento Estructural

Archivos involucrados: components/Sidebar.js, components/TopBar.js, app/(main)/layout.js.

Problema: El sidebar y el TopBar asumen de forma rígida tamaños en píxeles que entran en conflicto. El uso de posicionamientos independientes de fixed top-12 y h-16 crea costuras débiles que se rompen con facilidad al redimensionar.

Solución: Unificar las costuras espaciales mediante variables CSS globales (--navbar-height: 4rem) o emplear un layout de Grid CSS de 2 niveles en el layout global, impidiendo físicamente que un módulo flote y se solape con otro.
