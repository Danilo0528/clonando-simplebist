# Blueprint: Rediseño de la Interfaz de Usuario

## Visión General

Este plan tiene como objetivo rediseñar la interfaz de usuario de la aplicación para que se asemeje a la imagen proporcionada por el usuario. La nueva interfaz contará con una barra lateral de navegación a la izquierda, un área de contenido principal a la derecha y una paleta de colores oscuros para una apariencia moderna y atractiva.

## Diseño y Estilo

*   **Paleta de Colores:** Se utilizará una paleta de colores oscuros, con un fondo principal de color gris oscuro (`#1E1E1E`), un color de acento para los elementos interactivos y texto en color blanco o gris claro para garantizar una buena legibilidad.
*   **Tipografía:** Se empleará una fuente sans-serif moderna y limpia para toda la aplicación.
*   **Iconografía:** Se utilizarán iconos para mejorar la navegación y la comprensión de las diferentes secciones de la aplicación.
*   **Componentes:** La interfaz se construirá utilizando un enfoque basado en componentes para garantizar la reutilización y la mantenibilidad del código.

## Plan de Implementación

1.  **Crear un nuevo archivo de layout:** Se creará un nuevo archivo `layout.js` que definirá la estructura general de la página, incluyendo la barra lateral y el área de contenido principal.
2.  **Diseñar la barra lateral:** Se creará un componente de barra lateral que contendrá los enlaces de navegación, el nivel del usuario y la barra de experiencia.
3.  **Diseñar el área de contenido principal:** Se diseñará el área de contenido principal para mostrar el panel de control con el mensaje de "Bienvenida", la sección de "Ganancias de este mes", el "Feed en vivo" y las "Ofertas destacadas".
4.  **Estilizar los componentes:** Se utilizará Tailwind CSS para estilizar todos los componentes y crear una apariencia moderna y atractiva.
5.  **Actualizar las páginas existentes:** Se actualizarán las páginas existentes para utilizar el nuevo diseño y los nuevos componentes.
